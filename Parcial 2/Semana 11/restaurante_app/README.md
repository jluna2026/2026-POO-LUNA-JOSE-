# LUNA AVILA JOSE EDUARDO

## Descripción
Sistema de gestión para restaurante desarrollado en Python.

## Funcionalidades

- Registro de productos
- Registro de usuarios
- Venta de productos
- Control de stock
- Consulta de ventas por usuario
- Persistencia con JSON

## Persistencia

- productos.json
- usuarios.json
- ventas.json

## Excepciones controladas

- FileNotFoundError
- JSONDecodeError
- PermissionError
- KeyError
- ValueError

## Ejecución

python main.py

## Pruebas realizadas

- Registro de usuarios
- Registro de productos
- Venta válida
- Venta con stock insuficiente
- Recuperación de datos después de reiniciar
