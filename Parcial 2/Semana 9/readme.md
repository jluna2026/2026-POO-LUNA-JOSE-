## Descripción del Sistema
Aplicación modular desarrollada en Python para administrar los productos del menú y los usuarios registrados en un restaurante. El sistema permite realizar operaciones CRUD completas sobre productos y gestión básica de usuarios garantizando la integridad de los datos por consola.
